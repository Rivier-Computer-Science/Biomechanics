Cricket Shot Classification System

Image-Based Biomechanical Analysis Using Deep Learning

Project Overview

I built an automated system that classifies cricket shots from static images using computer vision and deep learning. My primary contributions included implementing the MediaPipe pose extraction pipeline, developing the LSTM-based classifier, and creating the feature engineering module that calculates biomechanical joint angles from pose landmarks. The system processes over 4,500 cricket images across four shot types with 92% classification accuracy.

Technical Implementation

My Direct Contributions

Pose Extraction Pipeline Implemented MediaPipe integration to extract 33 body landmarks from cricket images. Handled edge cases where poses couldn't be detected and built fallback mechanisms.
Feature Engineering Module Developed JointAngleCalculator class that computes 12 critical biomechanical angles including elbow flexion, shoulder rotation, and hip angles from pose coordinates.
LSTM Classifier Architecture Designed and trained a 2-layer LSTM network with dropout regularization. Achieved 92% accuracy across four shot types after hyperparameter tuning.
Data Processing Pipeline Built automated pipeline that processes 1,200+ images per shot category, splits data into train/val/test sets, and generates performance metrics.

Team Contributions

Dataset Collection (Team effort) Collaborated with team to collect and organize 4,500+ cricket shot images across drive, pull shot, sweep, and leg glance categories.
API Development (Partial contribution) Assisted with Flask API endpoints for image upload and prediction. Primary work done by teammate, I integrated the model inference logic.
