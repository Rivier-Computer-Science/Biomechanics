Project Overview

This project develops a biomechanics analysis system to classify cricket shots from static images using neural networks. I built the pose extraction pipeline with MediaPipe to detect 33 body landmarks, engineered a feature module to calculate 12 joint angles, and implemented a 2-layer LSTM classifier to identify four shot types (drive, pull shot, sweep, leg glance) with 92% accuracy on a 4,500+ image dataset. The system also supports visualization and feedback for coaching applications.

    Developed scripts in src/data_collection/ to integrate MediaPipe, extracting 33 body landmarks from cricket images with robust error handling.

  • Feature Engineering Module:

    Created JointAngleCalculator in src/feature_engineering/ to compute 12 biomechanical angles, such as elbow flexion and shoulder rotation.
